# Songwriters Tracking Sheets

Customized royalty dashboard templates built to help independent musicians track sales, publishing, licensing, splits, and account ledgers in one place.

## What It Solves
Songwriters and indie artists often juggle royalty statements across multiple platforms (streaming, publishing, sync/licensing) with no unified way to see the full picture. This tool brings it together into a clean, trackable format.

## Tech Stack
- HTML / CSS / JavaScript
- Netlify (hosting)

## Status
Actively developed, built for sale to independent musicians and songwriters.
